# Demo flow

1. Start FastAPI.
2. Start Vite.
3. Open **Overview** and show seeded complaint metrics.
4. Open **Complaint Analyzer**.
5. Submit: `There is a large pothole near the school and vehicles are struggling to pass.`
6. Explain category, department, confidence, urgency, duplicate/similarity and human-review flag.
7. Open **Complaint Queue** to show stored local records.
8. Open **Cluster Explorer** to show potential emerging cluster signals.
9. Open **Model Evaluation** to explain where actual metrics appear after training.
